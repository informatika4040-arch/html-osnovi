Гіпертекст і мова розмічання HTML

Гіпертекст — це текст із вбудованими зв’язками (гіперпосиланнями), що дають змогу миттєво переходити між фрагментами або документами. HTML (HyperText Markup Language) — мова розмічання гіпертекстового документа, яка описує його логічну структуру та елементи.

Мова розмічання vs Мова програмування

  • HTML — мова розмічання: визначає структуру документа (заголовки, абзаци, списки, посилання, зображення). Не містить циклів, умов чи обчислень.
  • Мови програмування (Python, JavaScript, C++): описують алгоритми, обробку даних, умови, цикли та поведінку програм.
  • Взаємодія у веб: браузер розбирає HTML-розмітку й будує дерево елементів (DOM), а JavaScript додає інтерактивність.

Базова структура HTML-документа

<!DOCTYPE html>
<html lang="uk">
  <head>
    <meta charset="UTF-8">
    <title>Назва сторінки</title>
  </head>
  <body>
    <h1>Заголовок сторінки</h1>
    <p>Основний текст документа.</p>
  </body>
</html>

Тег — команда розмічання у кутових дужках (<p>...</p> або одинарний <br>); атрибут уточнює властивості тега (наприклад, href, src, alt).
